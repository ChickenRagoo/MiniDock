# MiniDock — нативная версия на Rust

Тот же MiniDock (док, верхняя панель, Launchpad, Spotlight, Alt+Tab в стиле macOS), переписанный
с Python/PySide6 на Rust + Win32. Настройки общие с Python-версией: `%APPDATA%\MiniDock\config.json`.

## Сборка

```bash
cargo build --release
```

Бинарник: `target/release/minidock.exe` (≈2 МБ, без зависимостей). Нужны Rust (stable) и MSVC Build Tools.

## Как устроено

- **Отрисовка** — процессором (tiny-skia) прямо в буферы слоистых окон (UpdateLayeredWindow).
  Контекстов видеокарты нет вовсе, поэтому драйвер не раздувает память на каждое окно.
- **Размытие** — нативное Acrylic Windows в отдельном окне-подложке по форме панели.
- **Текст** — шрифты Segoe UI отображаются в память из файлов (ab_glyph), кэш глифов.
- **Цикл** — обычный GetMessage: в покое поток спит. Кадры идут от ожидания кадровой развёртки
  (D3DKMTWaitForVerticalBlankEvent, запасной вариант — DwmFlush) и только пока что-то движется.
- **События окон** — SetWinEventHook, без опроса. Клавиатурный хук WH_KEYBOARD_LL — в своём потоке.
- **Миниатюры** — DwmRegisterThumbnail (живые, видео играет); «подглядывание» — DwmpActivateLivePreview.
- **Иконки** — IShellItemImageFactory; каталог «Пуска» индексируется в фоне, иконки кэшируются на диск
  и выгружаются из памяти, когда Launchpad/Spotlight закрыты.
- **Spotlight** — поиск на любом языке и в любой раскладке (как в 1.9.0) + нечёткий поиск nucleo.
- **Анимации окон** — «джинн»/«масштаб» на живых DWM-миниатюрах без изменения стиля чужих окон
  (так исправлен баг с Photoshop: окно не делается прозрачным, ему нечего «сломать»).

## Замеры (Windows 10, 2560×1440, 180 Гц)

- Собственная память процесса в покое: ~14 МБ. Помощник «живого стекла» дока (`--glass-helper`, лупа Windows)
  — ещё ~43 МБ; без живого размытия в настройках он не запускается.
- Процессор в покое: ~0,2% одного ядра (часы на панели раз в секунду), в диспетчере задач — 0%.
- Анимации дока ~170 кадров/с, анимации окон ~100 кадров/с (их ограничивает DWM при обновлении миниатюр).

## Что нового по сравнению с Python-версией

- Большие часы посреди экрана, пока зажато сочетание (по умолчанию Alt+\`, меняется в настройках).
- Настройка «Док поверх полноэкранных программ»: в играх и видео на весь экран док прячется у края
  и выезжает по наведению.

## Что пока не перенесено

- Свои виджеты на Python (`%APPDATA%\MiniDock\widgets\*.py`, например VPN Handler) и виджет лимитов Claude.
- Автообновление с GitHub и режим «Работать с правами администратора».
- «Удалить с компьютера» в Launchpad открывает «Приложения и возможности» Windows вместо своего деинсталлятора;
  выделение нескольких приложений рамкой в Launchpad.
- «Живое стекло» (размытый фон, который окно рисует само, как в Python-версии) пока только у дока;
  панель, меню, Spotlight, Alt+Tab и остальные окна размывает Windows (отдельная подложка под окном).

## Проверка без мыши

`minidock.exe --cmd "click X Y"`, `--cmd "hook 9"` (Spotlight), `--cmd "minimize notepad"` и т. п. —
см. `src/testcmd.rs`. Отладочный журнал включается файлом `%APPDATA%\MiniDock\debug.flag`.
