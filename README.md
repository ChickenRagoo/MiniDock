# MiniDock

Док, верхняя панель, Launchpad, Spotlight и переключатель окон в стиле macOS для **Windows 10**.

- **Док** вместо панели задач: увеличение иконок, автоскрытие, размытый фон, папки, предпросмотр окон при наведении.
- **Анимации окон** «джинн» и «масштаб» при сворачивании, разворачивании и закрытии — в такт монитору (120/144/180 Гц).
- **Верхняя панель** со своими окнами трея, Wi‑Fi, звука, часов и раскладки.
- **Alt+Tab** в двух стилях: значки программ и их окна (как в macOS) или миниатюры всех окон со значками (как в Windows).
- **Живое размытие**: фон под доком и всплывающими окнами обновляется на лету.
- **Звук**: громкость и микрофон, громкость программ, выбор устройств вывода и ввода, карточки плееров с обложками.
- **Launchpad** вместо «Пуска»: все приложения или плитки из «Пуска», папки, выделение рамкой, удаление программ с компьютера.
- **Spotlight** (Alt+Space): приложения, файлы, калькулятор, системные команды, автодополнение по Tab.
- **Несколько мониторов**: док и верхняя панель на каждом экране (включается в настройках).
- **Режим администратора** — чтобы Alt+Tab, Win и Alt+Space работали и поверх программ, запущенных от администратора.
- **Автообновление** с GitHub Releases.

## Установка

Скачайте `MiniDock-Setup-x.y.z.exe` со страницы [Releases](../../releases/latest) и запустите.
Права администратора не нужны — программа ставится в папку пользователя.

Установщик без цифровой подписи, поэтому Windows покажет окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

Вернуть всё как было: правый клик по доку → «Выход» или ярлык «Выйти из MiniDock» в меню «Пуск».
Панель задач и рабочая область восстанавливаются при выходе и при удалении.

## Виджеты верхней панели

Короткая надпись на панели, по клику — окно с подробностями. Встроенные: «Система» (процессор, память,
диски, самые нагружающие процессы) и «Сеть» (скорость загрузки и отдачи). Включаются в настройках:
«Верхняя панель» → «Виджеты».

Свои виджеты — файлы `.py` в папке `%APPDATA%\MiniDock\widgets`. Там лежит пример `_example_widget.py`,
а все возможности описаны в начале [minidock/barwidgets.py](minidock/barwidgets.py): виджет в фоне
собирает данные (можно ходить в интернет, читать файлы), а окно строится из строк — заголовков, значений,
полос заполнения и кнопок.

## Фоны и виджеты в доке

Любой части интерфейса — доку, верхней панели, её окнам, Alt+Tab, миниатюрам, Spotlight, папкам, меню,
Launchpad — можно поставить свою картинку фона: «Настройки» → «Фоны». У каждой своя прозрачность.

Виджеты ставятся и в док: правый клик по доку → «Добавить виджет». «Плеер» — широкая плитка с обложкой
того, что играет (Spotify, YouTube в браузере и т.п.), и кнопками «назад / пауза / вперёд» прямо в доке.
«Система» и «Claude» — кольца загрузки и лимитов. Клик по виджету открывает подробности над доком.

## Запуск из исходников

Нужен Python 3.12 (64-bit).

```bat
pip install -r requirements.txt
pythonw MiniDock.pyw
```

Выйти: `pythonw MiniDock.pyw --quit`. Другие команды запущенному доку: `--launchpad`, `--spotlight`, `--settings`.

## Сборка установщика

Нужны [Inno Setup 6](https://jrsoftware.org/isinfo.php) и `pip install pyinstaller pillow`.

```bat
powershell -ExecutionPolicy Bypass -File build\build.ps1
```

Готовый установщик появится в `release\`. Новая версия: поднимите `__version__` в `minidock/version.py`,
соберите установщик и опубликуйте релиз — у всех, у кого стоит MiniDock, он обновится сам:

```bat
python build\publish_release.py ChickenRagoo/MiniDock v1.3.1 release\MiniDock-Setup-1.3.1.exe "Что нового"
```

## Структура

```
MiniDock.pyw        точка входа
minidock/           код программы
  app.py            запуск, команды, события окон
  dock.py           док и папки дока (folders.py — окно папки)
  menubar.py        верхняя панель и её всплывающие окна (flyouts.py)
  switcher.py       Alt+Tab
  launchpad.py      Launchpad
  spotlight.py      Spotlight
  animations.py     анимации окон (gpu_genie.py — «джинн» на видеокарте)
  uninstall.py      удаление программ из Launchpad
  elevation.py      режим «с правами администратора» (задание Планировщика)
  livecapture.py    живой фон «стекла» (лупа Windows в процессе-помощнике)
  audio.py, media.py  устройства звука и медиаплееры для окна звука (flyouts.py)
  updater.py        автообновление
  settings.py       окно настроек
build/              PyInstaller, Inno Setup, иконка
```

Установленная программа: `MiniDock.exe`, служебные файлы в `lib\`, деинсталлятор в `uninstall\`.
Настройки и журнал ошибок — в `%APPDATA%\MiniDock`.
